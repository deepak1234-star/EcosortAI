# EcoSort AI - AI-Powered Waste Classification & Recycling Assistant

EcoSort AI is an AI-powered waste management platform built with React, TypeScript, Tailwind CSS, Clerk Authentication, and Supabase.

## Features
- **Clerk Authentication Integration** with real Google OAuth redirection out-of-the-box (ccounts.google.com).
- **AI Computer Vision Waste Scanner** with low-confidence verification guidance.
- **Supabase Authentication & Database** for persistent user records and points ledger.
- **Immutable Eco Points Ledger** tracking all point transactions.
- **Community Action Hub** with duplicate submission prevention.
- **Atomic Reward Redemption** store.
- Mobile responsive UI (360px - 1440px).
